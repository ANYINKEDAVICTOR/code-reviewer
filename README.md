# Domain Reviewer (Kiro Power)

A structured, read-only code & project reviewer with custom domain rubrics, security checks, and visual Markdown/Mermaid reports.

## How to Install in Kiro IDE
1. Open **Kiro IDE** and click the **Powers** icon in the left sidebar.
2. Click **Add Custom Power -> Import power from GitHub**.
3. Paste this repository URL and click **Install**.

## Usage
Open any project in Kiro and ask:
- `/security-audit Review @<filename>`
- `Run a domain rubric review on @<filename>`
