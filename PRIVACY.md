# Privacy Policy for Code Reviewer

**Effective Date:** November 17, 2026  
**Author:** Anyinkeda Victor

## Data Handling & Local Execution
- **100% Local Static Analysis:** The `static_audit.py` script and `code-reviewer-mcp` stdio server run completely locally on your machine using Python's standard library.
- **No Telemetry or External Data Collection:** This Power does not collect analytics, track usage, or send your source code, credentials, or audit results to any third-party server operated by the author.
- **AI Model Processing:** When invoked inside Kiro IDE, Kiro CLI, or an ACP client, file snippets you explicitly share in chat are processed solely by the AI model session you already configured in your Kiro client under Kiro's privacy terms.
